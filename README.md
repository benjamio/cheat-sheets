# Cheat Sheets

A curated collection of concise, one-page cheat sheets for command-line tools and common workflows.

## Contents

- **tmux** — [cheatsheets/tmux.md](cheatsheets/tmux.md)

## Conventions

- Each cheat sheet aims to fit on a single printed page.
- Unless explicitly stated, sheets assume the tool’s default configuration on a POSIX-like system.
- Key notation:
  - `C-x` means **Ctrl** + `x`
  - `M-x` means **Alt/Meta** + `x`
  - `prefix x` means “press the tool’s prefix key, then press `x`”
- Each sheet includes a **Last updated** stamp.
